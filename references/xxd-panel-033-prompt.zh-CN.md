# XXD Panel 033｜现代杂志封面式平面拼贴生产提示词

只处理当前任务明确提供的这一张源照片。锁定主体或不可拆分关系、轮廓、比例、姿态、方向、动作、材质、环境结构、负形与颜色性格，至少保留三个源图专属识别线索。不要借用旧成品、样张或其他输入的母题、配色、文案、纹理与构图。

## 把源图提炼成一个可识别母题

不要机械描摹全部细节。提取最决定性的主体、轮廓、姿态、局部形状、环境片段或结构关系，把它转成更清楚、更鲜明的平面母题；缩略观看仍须一眼认出来自这张源图。

建立三个可读层次：由放大或重复的源图形状构成背景场；中层为占主导的主体；前景只保留一个克制点睛元素或一次文字穿插。用重复、层叠、放大、裁切、拼贴、遮挡形成节奏。允许自由偏心、越界与叠压，但始终只有一个明确焦点；重复不能退化成通用壁纸纹样。

建立一组决定性尺度对比：巨大与微小、近距离裁切与远处重复、密集色场与开放留白、深色压重与亮色提神。可以增加一个小尺度高对比元素制造第二拍或故事线索，但不得抢走主体。

## 源图配色与印刷触感

从照片提取最有生命力、辨识度和情绪感染力的颜色，压缩为一个主色、一至两个辅助色、一个深色压重和一个少量亮色点睛。允许高饱和，但要用面积和明度约束；禁止糖果色、灰脏色、固定套色和与源图无关的颜色。

使用平面编辑色块，并选择性加入颗粒、网点、网格、布纹、喷墨、拓印、干刷或套印错位。纹理只增加材料生命，不能破坏主体识别、焦点层级和文字阅读。拒绝写实渲染、光滑3D、普通商业插画、剪贴簿杂乱、模板化旅游海报、电商网格、卡通和廉价装饰。

## 文字是封面构图的一部分

自动文案从源图的主题、气质、动作、季节、材质、关系或有依据的潜台词中，提炼一个醒目主标题和一个更有情绪或叙事感的副标题。文案要与画面高度绑定并产生会心一击，而不是复述可见物体。不得虚构期号、日期、地点、时间、标签或事实。

文字可用超大字号横向穿插、纵向堆叠、局部遮挡、叠压母题、跨越色块或嵌入主动留白。始终尊重目标文字体系的真实字形与阅读方向。字体粗细、字距、断行、遮挡和尺度必须呼应母题形状与画面能量，不能像最后贴上的标题。

用户准确文案逐字保留，只添加确有信息价值的辅助文字。无文字模式仍保持同一母题、层次、配色、纹理和节奏系统，但不生成任何字母、字符、数字、词语或伪文字。

## 模式与验收

严格服从附加的 `OUTPUT MODE`、`FINAL SIZE` 与 `DESIGN FRAME`。双联模式只生成设计半幅；纯设计与壁纸不显示原照片。每张壁纸按设备重新构图，不裁切其他设备成果，不绘制系统 UI 或设备模型。连贯壁纸共同参考原照片与同一张已批准定调图，绝不串联衍生图。

硬性验收：至少三个源图线索；一个可识别的源图母题；背景、中层主体、前景点睛角色明确；一组决定性尺度对比与清楚焦点；重复和裁切来自源图；配色鲜明但受控；印刷纹理克制且真实；目标语言封面排版与图形一体；用户准确文案无改写；无虚构元数据；无模板森林、旅游广告、电商排版、卡通、剪贴簿杂乱、灰脏色、光滑3D、照片残片、样机或伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas 或后期文字覆盖伪造成品。
